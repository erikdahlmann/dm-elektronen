# Elektronenstrahlablenkröhre

Simulation der Ablenkung von Elektronen im homogenen elektrischen Feld, mit Heiz- und Ablenkspannung.

Live: https://erikdahlmann.github.io/dm-elektronen/
Früher auf Netlify: https://dm-elektronen.netlify.app/ (online seit 2026-05-08). Erstellt mit Gemini (Canvas).

Beim Umzug von Netlify entfernt: die Hilfsskripte, die Gemini Canvas beim Export einbaut (Firebase-Zugang, Abfangen von Netzanfragen mit API-Schlüssel). Die Seite braucht sie nicht.
